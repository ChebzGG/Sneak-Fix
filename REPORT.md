## 1. Общая информация о проекте и этапах разработки

Проект **SneakFix** представляет собой полнофункциональное адаптивное веб-приложение (SPA), разработанное пошагово в рамках учебной практики с соблюдением требований всех выданных заданий:

* **День 3–4:** Проектирование структуры, семантическая верстка адаптивного лендинга (HTML5/CSS3, Flexbox/Grid, Mobile-first, адаптивность 320px–1920px+, бургер-меню, интерактивные состояния).
* **День 5–6–7:** Адаптация проекта на **Vue.js 3**:
  * Компонент загрузки и валидации файлов Microsoft Excel (`.xlsx`, `.xls`) методом Drag-and-Drop и через системный диалог.
  * Модальное окно ошибки формата для неподходящих файлов.
  * Клиентский парсинг Excel-файлов (библиотека SheetJS) с импортом в реактивную таблицу данных.
  * Хранение реестра и метаданных файлов в `localStorage`.
  * Модуль авторизации, регистрации и восстановления пароля с валидацией «из коробки».
  * Таблица реестра заказов: пагинация (по 10 записей на страницу), кнопка ленивой подгрузки (Lazy Load), сквозной поиск по всем полям.
  * Модуль BREAD/CRUD: переиспользуемое модальное окно для добавления и редактирования записей, удаление с подтверждением.
  * Административная панель (Voyager Dashboard) со статистикой выручки и заказов.
  * Асинхронный API-сервис (`apiService.js`, `authService.js`) с поддержкой CRUD (GET, POST, PUT, DELETE) и версионированием.
* **День 8:** Полный перевод проекта на **Tailwind CSS** (utility-first, отказ от рукописного CSS, настройка дизайн-токенов в `tailwind.config`, аргументация выбора способа подключения).
* **День 9–10:** Реализация всех 4 уровней сложности Tailwind CSS:
  * **Уровень 1 (Начальный):**
    * *1.1:* Карточка профиля мастера (круглый аватар 80x80px, bio, Follow/Message, `w-full` на мобильных → `md:w-80` на десктопе).
    * *1.2:* Навигационная панель (sticky, backdrop-blur, z-50, логотип, навигация, Sign In, бургер).
    * *1.3:* Сетка из 6 карточек товаров каталога (`aspect-square`, `grid-cols-1 sm:grid-cols-2 lg:grid-cols-4`, `hover:scale-105`).
  * **Уровень 2 (Средний):**
    * *2.1:* Hero-секция (градиентный текст `bg-clip-text`, фоновое изображение с затемнением, две кнопки CTA, метрики).
    * *2.2:* Pricing-таблица (3 тарифа: Basic, Pro с бейджем Popular и кольцом `ring-2`, Enterprise; список преимуществ ✅/❌).
    * *2.3:* Сайдбар 256px + дашборд администратора Voyager.
    * *2.4:* Форма регистрации (`peer`, `peer-invalid`, 4-уровневый индикатор силы пароля, чекбокс согласия, кнопка с лоадером).
  * **Уровень 3 (Продвинутый):**
    * *3.1:* Мессенджер мастерской (диалоги слева со счетчиками unread, сообщения справа свои/чужие, стилизованный скроллбар `[&::-webkit-scrollbar]:w-2`).
    * *3.2:* Kanban-доска заказов (3 колонки: To Do, In Progress, Done; карточки с приоритетами, drag handles, горизонтальный скролл `snap-x snap-mandatory`).
    * *3.3:* Комплексный лендинг (Navbar, Hero, Features 3 колонки, карусель отзывов на чистом CSS `snap-x`, Pricing, FAQ аккордеон через `<details>` + `group-open:*`, Footer 4 колонки).
    * *3.4:* Dark mode с переключателем (класс `dark` на html, иконки луны/солнца, поддержка `dark:*` на всех секциях).
  * **Уровень 4 (Экспертный):**
    * *4.1:* Дашборд аналитики (4 stat-карточки с трендами `+14.2%`, динамический график заказов по дням недели, таблица транзакций с фильтрами).
    * *4.2:* Многошаговая форма (степпер из 4 шагов с расчетом сметы: контакты → модель обуви → тариф с радио-карточками `has-[:checked]:*` → сводка и подтверждение).
    * *4.3:* E-commerce каталог с фильтрами (категория, range-слайдер цены, сортировка, пагинация, мобильный drawer снизу, скелетон-загрузка `animate-pulse`, `@container`).
    * *4.4:* Дизайн-система (UI Kit: токен-палитра, сетка кнопок `.btn-*`, бейджи, алерты, инпуты).
* **Методология Unslop:** Проведена глубокая ревизия интерфейса — устранены шаблонные аляповатые градиенты, случайные эмодзи в заголовках и несогласованные отступы. Внедрена сдержанная благородная палитра (Slate/Graphite + Deep Teal/Indigo), строгая сетка с шагом 4px и математика вложенных скруглений.

## 2. Сравнение Bootstrap и Tailwind CSS (День 8)

| Критерий | Twitter Bootstrap (v4/v5) | Tailwind CSS (v3.4+) |
| :--- | :--- | :--- |
| **Парадигма** | Component-first (библиотека готовых крупных блоков: `.btn`, `.card`, `.navbar`, `.modal`) | Utility-first (низкоуровневые утилитарные классы: `flex`, `p-4`, `rounded-xl`, `gap-2`) |
| **Индивидуальность дизайна** | Узнаваемый шаблонный стиль. Кастомизация требует глубокого переопределения CSS и борьбы со специфичностью селекторов. | Абсолютная свобода оформления прямо в HTML. Любой макет из Figma верстается без единого правила в отдельном CSS. |
| **Скорость прототипирования** | Быстро для типовых админок и MVP без индивидуального брендбука. | Быстро при разработке уникальных брендовых сайтов, исключает фазу придумывания имен классов (BEM). |
| **Размер стилей в проде** | Большой фиксированный объем CSS (если не собирать точечно через Sass). | Минимальный размер благодаря PurgeCSS / JIT: компилируются только фактически использованные утилиты. |
| **JS-интерактивность** | Включает готовые JS-плагины для дропдаунов и модалок. | Предоставляет только стили; интерактивное поведение пишется на Vue / React / JS. |

### Аргументация применения:
* **Bootstrap** целесообразно использовать для внутренних корпоративных систем, учетных панелей и прототипов «на вчера», где дизайн вторичен по отношению к функциональности.
* **Tailwind CSS** является стандартом современной продуктовой разработки, где важны индивидуальная айдентика, точный контроль отступов и типографики, а также бесшовная интеграция с компонентными фреймворками (Vue, React).

## 3. Выбор способа подключения Tailwind CSS

**Выбранный способ:** **Tailwind CSS v3.4 Play CDN** (`https://cdn.tailwindcss.com?plugins=container-queries`) с выносом конфигурации токенов в `tailwind.config` и повторно используемых стилей в директивы `@layer components` и `@layer utilities` через `@apply`.

### Обоснование выбора:
1. **Автономность и переносимость:** Проект запускается в любом браузере простым открытием `index.html` или через Live Server без необходимости предварительной установки `node_modules`, сборщиков Webpack/Vite и фоновых процессов `npx tailwindcss -w`.
2. **JIT (Just-In-Time) прямо в браузере:** Скрипт CDN на лету компилирует классы при рендеринге DOM, включая сложные селекторы (например, `has-[:checked]:*`, `peer-invalid:*`, container queries `@container`).
3. **Чистота кода с @apply:** Повторяющиеся комбинации классов инкапсулированы в компоненты `.btn-primary`, `.card-surface`, `.input-field`, `.badge-*`, что предотвращает загромождение разметки.

## 4. Архитектура приложения Vue.js и сервисов

### Структура каталога `SneakFix`:
```
SneakFix/
├── index.html            # Главное одностраничное приложение (SPA)
├── REPORT.md             # Настоящий итоговый отчет
├── css/
│   └── style.css         # Стили компонентов @layer и токенов
├── js/
│   ├── apiService.js     # Асинхронный сервис заказов, парсинга Excel и CRUD
│   ├── authService.js    # Сервис аутентификации, сессий и ролей
│   └── main.js           # Корневой экземпляр Vue 3 с реактивным состоянием
└── img/                  # Графические ресурсы (до/после, товары, мастер)
    ├── master.jpg
    ├── master-cover.jpg
    ├── before.jpg
    ├── after.jpg
    └── shoe-1.jpg ... shoe-8.jpg
```

### Реализованный функционал:
1. **Интеграция Excel:**
   - Поддерживаются методы Drag-and-Drop и диалог выбора файла.
   - Метод `apiService.validateFile()` проверяет расширение файла. Неподходящие форматы мгновенно открывают модальное окно с пояснением.
   - SheetJS читает бинарный поток, формирует объекты заказов и обновляет реактивный массив `tableData` с записью в `localStorage`.
2. **Аутентификация и ролевая модель (RBAC):**
   - Реализована строгая модель разграничения прав доступа:
     - **Гость (неавторизованный):** только просмотр сайта, калькулятора, каталога и поиск по реестру заказов. Удаление, редактирование, добавление заказов и импорт Excel заблокированы. При попытке входа в панель аналитики отображается экран ограничения доступа.
     - **Клиент (`user`):** оформление заявок из онлайн-калькулятора, заказ товаров в корзине, отслеживание личных заказов.
     - **Мастер-реставратор (`master`):** управление этапами в Kanban-доске, добавление и редактирование записей в реестре заказов, пакетный импорт Excel.
     - **Администратор (`admin`):** полный доступ к аналитической панели Voyager (выручка, остатки склада, финансовые транзакции), удаление записей из базы данных, управление дизайн-системой.
   - Полноценная аутентификация через модальное окно: штатные аккаунты сервиса — Администратор (`admin@sneakfix.by` / `admin123`), Мастер (`master@sneakfix.by` / `master123`), Клиент (`client@sneakfix.by` / `client123`), а также мгновенная регистрация новых клиентов с валидацией пароля и сессиями в `localStorage`.
3. **Оптимизация навигации (Unslop):**
   - Верхняя панель разгружена: оставлены 4 ключевые ссылки («Услуги и цены», «До и После», «Калькулятор», «Магазин») и компактное выпадающее меню «Ещё» для второстепенных разделов.
4. **Управление заказами (BREAD):**
   - Таблица поддерживает фильтрацию, сортировку, постраничную пагинацию (10 записей) и режим Lazy Load.
   - Единое модальное окно переиспользуется для добавления нового заказа и редактирования существующих данных.
   - Удаление записей разрешено исключительно Администратору.
